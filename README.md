# Shadowrocket 分流规则

## 内容与使用

[`rules.conf`](rules.conf) 只含 `[Rule]` 段，共 4,902 条有效规则。它不是完整的小火箭配置，不能作为包含节点的订阅使用，也不建议直接替换正在工作的完整配置。

备份现有配置后，将本文件的 `[Rule]` 内容合并到现有配置中。`DIRECT` 表示直连；`PROXY` 表示代理策略，使用自定义策略组时请将其替换为自己的策略组名。文件不选择出口国家，也不提供节点。

规则按顺序首次匹配：

1. Google、Meta、ChatGPT / OpenAI、Claude、X / Twitter、Grok / xAI、海外 TikTok 等已收录域名优先走代理。
2. 中国抖音、QQ / 微信、快手、Pap X 及已收录的国内应用域名直连。
3. 局域网、回环和链路本地等保留地址直连。
4. 保留 `GEOIP,CN,DIRECT`；未命中前面任何规则的目标均由 `FINAL,DIRECT` 直连，包括未收录的海外目标。

所有原有海外代理规则保留，并排在国内规则和直连兜底之前；不是只保留少数重点服务。已收录的抖音与 TikTok 域名按规则顺序处理，未匹配的共享域名也会遵循 `FINAL,DIRECT`。

**隐私取舍：只有命中代理规则的连接才走代理。** 同一 App 的新域名、未收录第三方接口，以及其他未知海外目标可能直连、无法访问或向服务暴露本地出口 IP；不能保证整款 App 的全部连接均走代理。本文件不修改 DNS、IPv6、WebRTC、证书、脚本或系统代理设置，不保证消除所有泄漏，也不改变 IP 信誉或账号地区。配套私人配置在本次修改中也保留原 DNS、节点和策略组设置，代理策略并不等同于固定美国出口。

当前内容是经过规则语法、顺序和典型域名匹配检查的静态快照，不代表所有应用、网络和未来新增域名都经过实机验证。仓库未设置自动更新。

## 隐私边界

仓库不包含 `[Proxy]`、`[Proxy Group]`、`[General]`、`[Host]`，不包含个人服务器地址、端口、节点名、密码、UUID、密钥、订阅地址或浏览器数据。原有私人策略组名已统一替换为 `PROXY`。IP 段规则仅包含通用保留地址范围。

只在独立目录中发布规则及必要的说明、许可证；`.gitignore` 默认忽略未列入白名单的文件。仍请在每次提交前检查暂存区，切勿将完整个人配置提交到公开仓库。
